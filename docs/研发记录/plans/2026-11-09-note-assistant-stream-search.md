# AI 笔记助手流式回复与查资料

1. 沿用兼容 Chat Completions 请求，逐段显示正文，保留取消、非流式回退与完整结果校验。增量工具参数只进入缓冲区。
2. 输入区按消息选择查资料并填写关键词。服务端验证 FlowMuse 会话，只将关键词发给配置的检索服务。答案展示可核对的外部来源，整理稿确认写入时保留来源。
3. 测试拆包、断流、停止、完整工具动作、普通会话和搜索隐私边界。验证客户端相关测试与服务端测试，确认旧服务或缺少密钥时可正常使用普通会话。
