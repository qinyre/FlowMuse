# 搜索与笔记批量操作栏视觉调整

## Context

用户反馈搜索框的灰色填充、蓝色“本地标题”标签，以及铺满整行的批量操作栏过于突兀。本轮延续本地 `fix/settings-panel-motion` 分支，保留前一轮设置页改动。

## 实现范围

- 搜索复用 Material SearchBar 和现有搜索状态，采用主题 surface 浅底、细描边及清楚的聚焦态；去掉输入框内的实心标签。
- 搜索范围改为图标筛选按钮和轻量说明，长名称省略、窄屏换行，避免重复显示整条搜索词。
- 笔记批量栏复用 NoteBulkActionBar，宽度受控、减小边距；数量与图标形成识别区，操作添加图标，取消退到末尾。保留零选中禁用、回收站操作、异步菜单及回调。
- 只修改展示样式，不改查询算法、数据存储、删除确认流程或协作协议；不新增依赖。

## 验证

先运行搜索、批量栏、主题和集合页相关测试；检查默认/深色主题、窄屏大字号、筛选、删除/恢复/取消及菜单回调，再运行 analyze 与全量测试。本地 Web release 构建后检查真实视觉与交互。本轮未要求推送部署或 PR。

## 自动验证结果

- 搜索、批量栏、集合、主题和应用导航相关测试：14 通过。新增 4 项用例覆盖匹配数量与笔记本/标签组合筛选、空输入、浅/深色窄屏双倍字号和长名称、零选择禁用及移动/标签回调。
- `flutter analyze --no-pub`：通过，无问题。
- `flutter test --no-pub --reporter expanded`：2080 通过、5 个既有跳过，无失败。
- 现有查询也匹配副标题，本轮只将搜索说明同步为实际能力，未改匹配算法。
- 日志位于 `FlowMuse-App/build/search-selection-polish/`，不入库。
