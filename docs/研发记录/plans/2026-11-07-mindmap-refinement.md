# 思维导图布局与编辑优化

通用箭头在拖动时只更新端点，旧的曲线采样点会使连线扭曲。导图节点使用固定尺寸，长标签无法正确换行。

- 导图连线按移动后的父子节点重新生成整条曲线，保持原有元素 ID 和绑定。拖动节点时移动整个子树，拖动根节点移动全图。
- 节点按文字测量宽高，同层按列对齐，标签支持长文、多行和常用 Markdown。手工修改文字、新增分支与 AI 插入复用布局。
- 用深色根节点、浅色分支和无箭头的细曲线区分层级，长文本随节点宽度换行。
- 在节点操作中提供整理导图，旧导图可按现有结构重新布局。保持现有的场景、撤销和协作协议。

Flutter 回归覆盖鼠标和方向键移动、曲线锚点、分页边界、文字修改、撤销及重排。使用 Chrome 打开本地编辑器样稿，核对了长标签与列表显示，实测分支拖动和「整理导图」。双端协作、移动设备触控和真实模型调用待实测。
