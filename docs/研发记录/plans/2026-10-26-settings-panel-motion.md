# 设置页标题与分类切换

## Context

用户要求设置侧栏的“设置”标题横向居中、分类切换具有进出动画，并修复快速切换时中间标题叠字。工作区干净，主线为 `0fc05b3d`；PR #91 的资料库动效仍在独立分支，本轮从 main 新建 `fix/settings-panel-motion`，不混入资料库功能改动。复用该 PR 已验证的 Excalifont 测试夹具修复，使 presence 测试不再依赖 Google Fonts 下载；产品字体不变。

## 勘察

- 设置标题被放入 SharedSidebarHeader.trailing，因此靠右；返回按钮与标题应独立对齐。
- 设置正文按 section 立即替换；RightPageHeader 内的 AnimatedSwitcher 默认叠放所有 outgoing 标题，快速切换会积累多个旧标题。
- SettingsSectionBody 持有备份 busy/message 状态，不能为了动画给整页换 key 后销毁该状态，否则切回时可能重复启动仍在进行的操作。

## 方案

1. 复用侧栏页头，保持返回按钮左对齐，以对称边距和叠放布局让标题在侧栏几何中心。
2. 仅设置内容区使用一个动画控制器，旧内容淡出后再替换，新内容淡入并轻微上移；快速操作合并到最新 section，回到正在显示的分类则取消离场。
3. 内容保持原有元素身份，延续备份状态；离场中的旧内容不接收点击/键盘输入。主题等同分类属性更新不启动切换。
4. 共享页头只布局当前标题，避免旧标题堆叠；保留当前标题的进入动效。
5. 遵循 AppMotion 和减少动画设置，覆盖大字号、窄屏分类菜单、快速切换、返回当前分类、销毁及备份状态保留。
