# 手指先点选后拖动

> 2026-09-26 非选择工具的手指对象交互和自由笔迹点选规则已调整，现行方案见 [智能排版文案与触控笔模式下的手指选择](2026-09-26-final-touch-selection.md)。以下保留原始方案与验证记录。

## Context

关闭手指绘制后，现有实现会在非抓手工具下将命中对象的触摸临时交给选择工具，导致滚动笔记时误拖笔画和图片。按用户确认的规则收紧入口，复用既有选择、变换和页面导航逻辑。

## 交互规则

- 非选择工具：单指只移动页面，即使触点命中已选内容也不编辑对象；仍尊重单指平移和防误触设置。
- 选择工具：轻点并抬手才选中对象；未选中对象上的直接滑动只移动页面。
- 已选对象（手指或触控笔选中）：下一次触碰可拖动，选择框句柄仍支持调整大小和旋转。
- 轻点空白取消选择；滑动空白保留选择并移动页面。
- 轻点容差按屏幕距离计算；取消事件和双指页面手势不提交点选。
- 开启手指绘制、鼠标和触控笔沿用现有行为；不改变数据格式、历史记录和协作协议。

## 实现与验证

1. 收紧控制器触摸分流，选择工具只对已选对象及句柄启动拖动；未选中触点复用页面平移路径，抬手后执行点选。
2. 分页画布复用相同的点选入口及触摸容差，保留滚动到底部追加页面。
3. 回归点选后拖动、图片/笔画、空白取消、非选择工具平移、缩放下轻微抖动、取消/防误触、双指手势、撤销和鼠标/笔的直接拖动。
4. 运行定向测试、全量 Flutter 测试及静态检查，构建网页和 Android 测试包；记录真机验证范围。

关键文件：`markdraw_controller.dart`、`select_tool.dart`、`editor_canvas.dart` 及 `test/features/whiteboard/editor_core/` 下的手势测试。

## 验证记录

- 先用回归测试复现未选中图片被直接拖动、非选择工具误拖，以及轻微抖动移动对象；修复后通过。
- Widget 测试额外复现双指缩放识别前的原始指针事件误拖图片；第二根手指落下时取消单指编辑，已完成的移动仍保留撤销记录。
- 14 项定向测试通过；全量 Flutter 测试 1781 项通过、6 项既有跳过。
- 静态检查无新增问题；本地忽略的 `build/nav_compact_screenshot_test.dart:199` 仍有既有 `invalid_use_of_protected_member` 警告。
- 浏览器实际打开本地 release 网页，创建空白笔记并用鼠标直接拖动未选中矩形，选择框和位移正常；[界面截图](../evidence/touch-selection/web-mouse-regression.png) 仅用于鼠标回归，不作为手指真机验证。
- 自动验证覆盖分页和无限画布；Android 实机手感、鸿蒙触控笔与防误触仍需设备回归，模拟指针测试不等同于真机验收。
