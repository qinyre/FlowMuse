# 本地笔记双开

## 需求

在文档菜单提供「并排打开」。当前笔记可编辑，参考侧只读，支持本地笔记和已导入 PDF。双开和实时协作互斥，正在进行的房间保持连接。

## 实现

- 复用资料库索引选笔记，复用场景仓库和画布加载参考侧。参考侧仅从本地读取场景，使用独立控制器和缓存。
- 两栏各自滚动和缩放，可调宽度并交换左右。窄屏切换当前显示的笔记，保留两边画布状态。关闭参考侧后，在当前编辑会话内重新打开可恢复该参考笔记的位置。
- 在进入双开与创建、加入房间及好友邀请入口校验互斥。主笔记沿用已有保存和撤销流程。

## 验证

覆盖选择笔记、关闭和恢复参考侧、窄屏切换与协作互斥。运行前端静态检查及 Flutter 全量回归，并在 Web 核对宽窄两种布局。

白板集成用例通过实际菜单选择资料，验证只读参考侧、主画布实例保留、参考缩放恢复以及创建和加入房间被拦截。Chrome 用本地分页样稿核对了宽屏双栏、文档菜单和窄屏切换。平板触控和大 PDF 并行书写性能待实测。
