# PDF 协作逐页加载

PDF 导入已将每页保存为独立图片。开房时先同步页面和笔迹，随后上传底图；当前上传与下载都在整批结束后才交付结果。

1. 房主优先上传当前页和首页，每张图完成后同步对应元素状态，后续图片继续使用现有加密文件接口。
2. 参与方优先请求可见页，再预取相邻页。每张图独立进入编辑器文件缓存，视口变化时重新计算请求顺序。下载错误仅影响本机，可重试。
3. 保存本地副本、分享或导出前检查并补齐缺失附件，提示仍缺失的情况，避免生成不完整的文件。

验证覆盖首图早于慢图显示、翻页调度、单页失败重试、退房期间的异步请求及保存完整性。用大 PDF 在 Web 与平板之间对照入房至首屏底图显示的时间。
