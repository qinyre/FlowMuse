# 应用内使用指南与首次首页引导

## Context

用户希望首次使用时能够了解核心功能，并在设置末尾保留可重复访问的介绍。当前设置只有反馈邮箱和官网入口，没有应用内完整指南。分支 `feature/in-app-user-guide` 基于系统通知分支最新提交，保留待审 PR #99 的改动，不修改该 PR 分支。

## 需求与设计

- 新建独立使用指南，按“快速开始、书写与画布、PDF 阅读与批注、实时协作、智能工具、笔记管理、备份与偏好、好友与提醒”分章。每章独立路由，支持直达和返回。
- 设置宽屏导航最后增加“使用指南”；窄屏设置分类菜单同样提供入口。指南独立呈现，避免设置侧栏里再套一层侧栏。
- 首次首页使用非模态欢迎卡片，提供直接开始、了解功能和关闭操作。仅在空白资料库首次使用时出现，完成后在本机记忆；既有资料库不重复打扰。协作、文件和通知入口不增加弹窗或登录/权限要求。
- 内容复用，覆盖入口、操作步骤和边界：AI 需配置、好友功能需登录、笔身双击依赖设备、系统提醒需授权且不提供离线推送。涉及快捷操作时直接解释操作，不增加编辑器内的新弹层或逐笔提示。
- 沿用 FlowMuseSans、现有 ColorScheme、SharedSidebar、RightPageScaffold、AppSpacing 与 AppMotion。采用安静的手册排版、明确的目录层级和轻量主题化功能示意；示意图明确标注，不冒充实机截图。无需引入字体、第三方依赖或截图资源包。
- 宽屏目录与正文分离；窄屏和大字号顺序排版、正文可滚动。键盘焦点、语义标签、触控目标与减少动画设置保留。

设计参考：frontend-design、ui-ux-pro-max 的简洁阅读布局及 Flutter 响应式/无障碍建议；自动推荐的配色和西文字体不替代项目已建立的主题。

## 实现方案与关键文件

1. `features/guide/models/`：单份静态章节与步骤数据，不复制文档生成一套新功能逻辑。
2. `features/guide/views/` 与 `widgets/`：指南页面、功能示意、欢迎卡片；导航动作复用现有新建、设置与消息路由。
3. `features/guide/view_models/`：首次引导偏好复用 LocalSettingsRepository，读取失败不阻断首页，不改数据库结构。
4. `app/app_router.dart`：指南路由与缺失章节回退。
5. `features/settings/views/settings_page.dart`：宽窄屏常驻入口。
6. `features/library/views/library_home_page.dart` 与 `widgets/library_content.dart`：仅首页插入欢迎卡片，保留已有页签、列表和侧栏动画结构。
