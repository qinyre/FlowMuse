# 页面预览选择与删除

## 背景与范围

多页笔记已有底层单页删除方法，但页面预览只有跳转，使用者无法删除多余页面。本轮在既有预览中增加选择删除，保留缩略图按需渲染，不增加新页面管理界面。

## 交互与实现

- 编辑态预览提供“选择页面”；长按缩略图也进入选择。选择模式下点击切换勾选，不触发翻页，底部显示数量及删除按钮。
- 删除前确认会连同该页的笔迹、文本和 PDF 底稿删除，可一次撤销；至少保留一页。参考笔记等只读预览不提供删除。
- 复用 ToolResult、元素软删除、页面重排及阅读位置恢复；多页删除一次提交历史和场景变更，保留其他页内容、资产及页面 ID。兼容旧元素未记录页归属的情况，沿用创建时的中心点归页规则。
- 确认后再次核对页面是否存在、只读状态与编辑忙碌状态；远端或其他操作改变页面时，不按旧页码误删。
- 删除后缩略图立即更新并释放已删除页面的缓存；清理失效选择，支持随后撤销/重做。

## 验证

- 控制器覆盖首/中/末页、多选一次撤销重做、混合尺寸与两种排列、PDF 与旧归属元素、当前阅读位置、协作场景恢复以及最后一页和编辑忙碌保护。
- 预览测试覆盖点击/长按选择、取消与确认、只读、页面变更后的选择、缓存和缩略图刷新。
- 运行受影响静态检查与完整 Flutter 回归；匿名界面预览检查触控布局。未要求发布或安装，本轮不部署。

## 实施结果

- 已实现选择按钮、长按选择、勾选状态、底部删除、确认提示与只读/最后一页保护。删除页后缩略图即时刷新，清理删除页缓存及失效选择。
- 控制器集中处理批量删除，复用单页入口；按页归属及旧元素中心点归页软删除内容，保留附件供撤销，余页重新排列。删除当前页后定位后续最近存留页，后面没有页面时定位前面的最后一页；保留当前页时恢复原阅读位置与缩放。
- 31 项页面相关测试通过。完整 `flutter test --no-pub` 为 2166 项通过、5 项跳过；受影响 Dart 文件静态检查通过。使用指南新增入口说明，补充指南回归。
