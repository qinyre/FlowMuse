# 笔记 Agent 侧栏第一版

## 背景与范围

将白板中的表单式助手改成对话侧栏。宽屏为画布预留独立空间，紧凑布局允许收起侧栏回到画布。保留当前笔记编辑期间的草稿和消息。服务商请求继续使用现有适配，流式回复、跨笔记任务和持久化历史留到后续。

## 实施顺序

- [x] 先建立消息列表、底部输入区和会话生命周期。每条回复记录发出时的来源，旧回复仍能定位，发送、取消、草稿编辑和新建对话沿用现有校验。
- [x] 将面板接到编辑器的停靠布局。检查打开、调宽、收起、截图和引用回跳，覆盖宽窄窗口和平板键盘可用空间。双栏按主编辑区的宽度决定是否停靠。
- [x] 按迁移清单运行回归，验证整理稿自动续页、原稿保留和一次撤销，更新项目需求和实测范围。

## 迁移与验收

| 能力 | 验收 |
| --- | --- |
| 来源和附件 | 当前选区、当前页、整篇文字、PDF 页图、框选截图均可发送。附件可预览和移除，截图结束回到原会话。旧引用按原回复来源定位。 |
| 输入 | 原有画布入口、解释这段、整理为笔记、内置及自定义指令、语音、追问、取消、清除对话和模型配置继续可用。 |
| 写回 | 插入文本、改名、思维导图、智能排版和整理稿继续通过原动作确认链路。整理稿超过一页时，分页和 PDF 追加新页，无限画布放在内容旁。一次撤销移除当次新增内容，原稿保留。 |
| 会话边界 | 收起、截图和页内跳转保留会话，切换笔记或工作区销毁后清空。消息与附件留在本机内存，用户发送的选定上下文交给已配置模型，确认写回才使用原协作链路。 |

## 关键位置与验证

- `ai_agent_dialog.dart` 管理消息、来源、输入和动作卡。`whiteboard_page.dart` 管理编辑会话和画布入口。`markdraw_editor.dart` 负责视口与侧栏布局。
- 运行助手、白板编辑、双栏及布局定向测试，覆盖新旧引用和收起后草稿恢复。共享编辑器改动运行完整 Flutter 回归。记录可实际完成的 Web 和平板验证。

## 实现细节

- 宽屏按编辑器可用宽度停靠并支持拖动调整。窄屏在主编辑区展开，返回画布时保留会话。截图模式暂时让出画布，宽屏查看引用时对话保持可见。
- 消息列表保留本次编辑会话内的已完成回复。切换来源后旧消息仍可核对，其上下文不再随新请求发送。操作确认沿用最近一次回复，换来源后重新生成动作。
- 确认写入整理稿继续调用现有分页与撤销实现，完成后保留 Agent 会话。智能排版进入原有审阅流程。

## 验证结果

- Flutter 全量回归通过 2172 项，跳过 5 项。改动 Dart 文件静态分析通过。双栏额外验证参考笔记的宽度与位置不受 Agent 展开影响。
- 白板端到端控件测试使用 70 条推导步骤，验证预览前后画布、确认追加多页、保留会话及一次撤销。另有 PDF 自动续页和无限画布放置的既有回归。
- 本地 Chrome 使用匿名样稿及模拟回复验证 1200 像素宽屏和 390 像素窄屏的对话、引用及整理预览。真实模型服务与平板触控待实测。
