# 智能排版 UX 第二轮实施计划（页面入口/跳过逻辑/非模态确认条/文案）

> 依据 2026-08-25 与需求方确认结论。背景：MR #12 已合入 main 并部署；本轮补齐页面入口三选项、逐页跳过、非模态底部确认条（解决"失败红区被居中对话框遮挡"）、风格由 AI 自主决定（移除人工切换）、文案改名。

## 需求确认（已与需求方逐条确认）

| # | 结论 |
| --- | --- |
| R1 | 页面入口：点"智能排版"弹单对话框：顶部三选一 **全部页 / 选页 / 当前页**（默认当前页）；选中"选页"时旁侧显示**勾选列表（含页面缩略图+页码）**与**页码输入框**；单页笔记跳过弹窗直接执行 |
| R2 | 页码输入：`3-5` 表示 3..5 页，`3,5` 表示第 3、5 页，`3-5,7` 混合；格式错提示并阻止确定；**输入框输入 → 自动勾选对应页；只勾选 → 输入框清空** |
| R3 | 逐页预览：多页时可**跳过本页**继续；单页时不显示跳过，只显示取消 |
| R4 | 确认改**非模态底部悬浮条**：AI 自主定风格（移除风格 chips 与人工切换），画布全程可见（红区/蓝框不被遮挡）；按钮：应用 / （有失败时）删除未识别笔迹后应用 / 跳过本页（多页）/ 取消整个流程 |
| R5 | 失败提示同样改非模态底部条（红区可见）：N 处未识别成功 + 重新识别 / 跳过本页（多页）/ 取消 |
| R6 | 文案："仅转机器字体" → **"仅识别并转化手写字体"** |

## 关键改动

1. **`SmartLayoutPageRangeParser`**（纯 Dart）：`{3-5,7}` 解析、校验（1-based、a≤b、≤页数、去重、错误提示）。
2. **`SmartLayoutScopeDialog`** 替换 `SmartLayoutPagePickerDialog`：三选一 + 选页态（缩略图：`controller.exportRegionPng(page.bounds, maxLongestSide: 120)` → `Image.memory`，失败回落灰块；输入框与勾选双向同步）+ 返回 `(mode, pageIds)`。
3. **`SmartLayoutConfirmBar` / `SmartLayoutFailureBar`** 替换原居中对话框：`Positioned(bottom)` 悬浮卡片；按钮按 `isMultiPage`/`hasFailures` 动态显隐。
4. **Ghost 组合**：`SmartLayoutGhostSpec.preview` 增加 `failureRects`（默认空），painter 预览分支同时画红框 → 有失败+有计划时蓝框+灰框+红框同屏可见。
5. **`whiteboard_page`**：入口弹窗 → 逐页（`isMultiPage=selected.length>1`）→ 幽灵+底部条（`Completer` 等待动作）→ 应用/删除未识别后应用/跳过本页/取消整个流程；取消=停止后续页，已应用保留。移除风格切换与模态确认框使用。
6. **文案**：`SmartLayoutStyle.inPlace.displayName = '仅识别并转化手写字体'`；`_legacyPlacementPlan` 描述同步；相关测试断言更新。
