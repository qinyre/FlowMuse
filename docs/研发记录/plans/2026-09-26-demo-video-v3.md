# 复赛演示视频 v3

## Context 与需求
用户接受审片建议：提前展示特色，以同一份课程笔记串联八组功能，完善正式录屏的动作提示、鸿蒙能力标注、声音与成果回顾。队名为“青天小老爷”。保留翡翠墨色与暖金风格，各段时长可调；真实录屏和正式旁白尚未提供。

## 实现方案与关键文件
复用现有 HyperFrames 品牌片头、Remotion 场景、历史截图和概念图。修改视频工程的 timeline.json、Opening/Closing、Footage/FeatureVisual、Video 和样片入口；新增最小的共用成果镜头和音轨编排。原始长操作说明留在录制脚本，短标签用于画面。音源记录来源；无法取得现成授权音源时使用原创合成听感稿。保留 v2 输出，v3 另存。

## 实施步骤与验证
先改脚本、开场/收尾和镜头引导，再加入音轨。运行类型、时长与字幕回归，抽检各场景和开场/收尾切点，导出 32 秒样片与全片预演；核对 MP4 时长、音画轨道、音量和解码。依仓库规范完成 Flutter 静态检查与测试。应用、服务端及同步协议不在本次修改范围。

## 实施结果
已完成六项调整及“青天小老爷”署名，保留可调时长与全部八组功能。v3 样片和完整预演已分别导出32秒1080p30与288秒720p15；H.264/AAC音画轨通过解码校验，峰值分别−13.4与−14.2 dBFS。29个关键帧及编码后收尾画面审查通过。npm run check与正式缺素材拦截验证通过；Flutter analyze无error、1条既有warning，flutter test 1781通过/6跳过。视频仍缺八段实录和正式旁白；当前BGM是原创合成听感稿，Yaps最终字幕尚未制作。
