# V3 整页理解与图文关联

## 目标与范围

在 `6702677` 基线上增强现有 V3：模型看到同轮捕获的整页内容概览和完整已识别文字，判断标题、正文、列表、阅读顺序，并把图片与对应正文关联。V1、OCR 转写、源账本、确认应用/撤销和编辑器格式保持不变。不重新开发排版引擎。

## 实施步骤

1. **视觉结构输入**：复用 `DraftSceneRenderer` 生成内容范围概览（排除页面框/PDF 底图），保留图片真实裁剪、位置与比例；编号与 units 顺序严格对应。长边不超过既有 2048px、总像素不超过 2MP、base64 不超过 3MiB。缺图、渲染失败或预算用尽时明确降级，不把占位框当作可见图片。
2. **一次整页结构分析**：多段文本/图文页进入已有 structure 阶段；明确的单栏标题+单列表仍可走本地快路径，单一文本/纯图片不做无意义结构请求。已识别文字不再在服务端截断到 80 字；模型只能引用已有 ID，不返回或修改正文。整页图和其中的文字均为分析数据，不是指令。
3. **图文关系落地**：structure 请求增加可选 `includeFigureTextLinks`；仅协商该能力时返回 `figureTextLinks`，旧客户端响应键集不变。每项 `{textUnitId, figureUnitId, confidence}`；正文/列表文字与图片关联，不冒充 caption，一文至多一图、可一图多文。双端检查端点、角色、重复、置信度与图注冲突；低置信关系不参与自动排版。关系经 semantic extras 进入现有 keepWith 原子组，正文保持原角色，图片与相关文字同组排版；锁定/保留/缺失图片不强制入组。

## 运行约束

- 每次分析仍只有一个 structure 逻辑请求，沿用取消、代次与总调用预算；不对每张图片各调一次模型，不做整页 OCR 第二遍。
- 模型不可用时回退本地结构并说明未完成整页分析；不伪造关联或宣称理解成功。显式重新分析使用新快照和代次。
- 第一版关联是已有块级别；一个 OCR 块内部混有标题和正文时，不在本次凭空拆分源笔画；跨页关联、图片内文字转写、生成新内容不在范围。
- 超大图文组仍受现有候选安全约束，放不下不以截断、丢字或随意拆散冒充成功。
- 后端须先升级，再安装新客户端。没有真实模型/实机证据时，只报告自动化链路验证，不宣称实际配对准确率已达标。

## 验证

复用已有 Flutter/Go 测试：真实概览含图片且编号可定位；两张图与距离更远的正文交叉配对；无关联不硬配；正文超 80 字保留；错误 ID/重复/角色冲突拒绝；缺图和预算失败安全降级；关联从响应到语义块、实际放置连续传递；原文、源账本与原场景不变。运行 `flutter analyze`、`flutter test`、`go test ./...`、`go vet ./...`。按协议/分析链路和排版消费分阶段提交，不推送、部署或合并主干，除非用户另行要求。
