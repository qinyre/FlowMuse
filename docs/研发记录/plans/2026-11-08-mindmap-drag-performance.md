# 思维导图根节点拖动优化

## 范围与方案

根节点带动大量子节点时，选择工具逐个构建临时场景，连线按节点重复扫描全场景，最终 CompoundResult 又逐个复制场景。先优化已确认的计算开销，不改变树布局、绑定语义、元素版本规则或协作协议。

- 不可变 Scene 按快照缓存 ID 与箭头绑定索引，继续返回查询结果副本。
- 批量替换连续的元素更新，保留新增、删除、选择、嵌套复合操作的先后顺序；同 ID 后写覆盖、不插入不存在的元素。
- 拖动临时场景一次更新所有移动节点，连线仍使用原有端点计算和去重规则。

## 验证

完整 Flutter 回归覆盖保存、撤销和协作；补充批量操作与快照缓存语义测试、大树整体位移和连线一致性回归。使用同一合成导图和拖动路径测量改动前后 CPU 时间，不将该时间解释为浏览器或平板帧率。实现阶段未部署；正式 Web 发布见文末，后续实机体验需复测。

## 实施结果

- 已完成 ID/绑定查询索引、临时场景批量替换，以及 CompoundResult 中连续 UpdateElementResult 的批量应用。新增、删除、嵌套操作仍按原次序执行，保留软删除、文件与元素快照语义；未修改渲染策略或协作协议。
- 增加批量操作与逐项操作对照、旧快照查询隔离、双端绑定去重、删除/远端更新，以及 161 节点实际控制器拖动、全体标签和连线位移、一次撤销重做的回归。
- 完整 `flutter test --no-pub`：2169 项通过、5 项跳过。受影响源码与测试静态检查通过，性能测量工具另外检查与执行。
