# 公开文字资料隐私清理

## 范围

清理主项目 README、开发说明、研发记录与官网中的成员姓名、个人网名、学校身份和个人电脑用户名。使用项目组或岗位称谓保留必要的职责与技术背景；反馈邮箱保持原样。

用户确认仅处理当前文字版本，不改写 Git 历史，不修改截图和视频。第三方许可署名、必要项目链接及应用标识按原用途保留，不改动应用功能、测试夹具或部署凭据。

## 实施与验证

- 扫描两个仓库的已跟踪文字文件及远端分支，排除第三方许可材料，区分测试数据、项目配置与个人身份。
- 清理维护者及责任人信息，修订公开文档规则；研发审查记录中的个人目录改成通用开发者目录，除该描述外保留原有 JSON 内容。
- 主项目与官网的用户协议保持一致，沿用已上线的源码许可说明，只调整项目称谓和文本修订日期；官网页脚移除学校身份。
- 校验个人身份关键词、反馈邮箱、HTML 锚点、JSON 内容边界、第三方许可和 diff；运行官网既有静态资源/交互检查。纯文字改动不重编 App 或重启后端。
- 官网以独立版本目录发布，核对实际 HTTPS 正文及资源哈希；远端分支仅追加脱敏提交，不覆盖既有提交历史。
