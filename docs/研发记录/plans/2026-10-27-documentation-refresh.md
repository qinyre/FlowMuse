# 项目文档同步与清理

## Context

从已合并设置 UI PR #93 的 main `97c2a6c4` 建立 `chore/docs-refresh`。用户要求更新项目文档，并清理过时、重复或未实际采用的材料。

## 范围

- 盘点 Git 跟踪的一方文档，核对 README、需求、技术设计、开发约定及决赛计划与实际代码、配置、合并和发布记录的关系。
- 当前说明负责描述现状；研发记录保留当时的方案和证据，明确其时间与替代关系，不改写历史验收结论。
- 删除已经被实际方案取代的重复建议、未落地的实验方案及无独立用途的材料；先检查正文、引用和工具依赖，保留协议、测试夹具、许可证、有效设计决策与验收记录。
- 本地忽略的课程/参赛原件、第三方自带文档、用户数据及编译产物不在本次删除范围。

## 验证与交付

检查相对链接、现存路径、删除文件的残留引用、文档与配置一致性及 Git diff。仅修改文档，分批本地提交；不因此重新部署应用或改动运行代码。
