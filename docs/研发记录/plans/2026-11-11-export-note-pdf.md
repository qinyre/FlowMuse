# 白板导出为 PDF

在宽屏和紧凑文档菜单新增「导出为 PDF」。分页笔记按阅读顺序生成 PDF，每页保留纸张比例、底图与批注。无限画布将内容按比例放到一页。导出使用开始时的场景快照，依次渲染每页并显示进度，合作笔记先补齐所需底图。

PDF 编码共用 Dart 实现。Web 下载文件，Android 和 iOS 由选择器写入，桌面使用所选路径。鸿蒙通过已有的 Core File Kit 保存通道打开系统选择器，传入 PDF 字节和建议文件名。

用混合方向的分页笔记验证页数、顺序、底图和批注，并覆盖无限画布、鸿蒙通道参数及取消保存。构建 Web 并检查鸿蒙构建环境。

编码依赖按需加载，使用 `pdf 3.12.0`（Apache-2.0）及 `image 4.5.4`（MIT）。其新增传递依赖 `barcode 2.2.9`（Apache-2.0）、`bidi 2.0.13`（MIT）及兼容的 `xml 6.6.1`（MIT）已对照解析包中的许可文件。每页最长边 2000 像素，以 JPEG 嵌入，原始像素只保留当前页。

本机验证：全量 Flutter 测试 2242 项通过、5 项跳过。Poppler 打开混合方向的两页样张，确认底图顺序及第二页批注位置。Web release 构建通过，Chrome 从文档菜单下载的文件可打开。安卓、鸿蒙保存通道的测试通过；当前机器缺少可用的鸿蒙 SDK，HAP 构建和真机操作待验证。
