# AI 菜单与 Web 截图修复

- 助手使用路由内的 OverlayPortal，使来源菜单和其他弹层按路由顺序显示。截图期间隐藏助手并保留表单状态。
- 来源和模型预设采用应用现有的锚点菜单，保留键盘操作、点击外部关闭和原有主题。
- CanvasKit 的编码图片描述符不提供宽高。读取 PNG 的 IHDR 并检查块结构，再执行现有的像素和字节上限检查。实际需要缩放时才解码。
- 用真实白板入口验证来源菜单可点击，用 Chrome 运行截图回归，并核对设置预设仍可正常选取。

## 验证记录

- 白板路由交互测试确认来源菜单位于助手上方，可选择并返回面板。设置交互测试确认预设选择与密钥隔离。
- 在本地 CanvasKit 发布构建中运行 Chrome 验证，复现旧尺寸读取接口抛出 `UnsupportedError`，新流程通过框选截图、所选元素截图、PNG 校验和大图缩放。
