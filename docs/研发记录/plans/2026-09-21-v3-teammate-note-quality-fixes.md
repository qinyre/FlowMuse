## 顺序与完成条件

1. **内容完整性**：追踪手绘图形是否混入 OCR 目标；阻止文字响应吞掉非文字笔迹，保留不确定原件。补充实际原稿分区诊断和小型可移植回归，覆盖混合图文与纠错重跑。
2. **结构完整性**：定位章节编号脱离正文、双图共说明被拆散的原因。在已有分区/语义组内修复；不可确定的关联保持原样，不猜文字，不删除短笔画。
3. **尺度与可读性**：区分真实字体/构图尺寸与预览缩放。复用页面尺度和测量，修复字图比例、组内排列和异常留白，不靠扩大所有元素填满页面。
4. **推荐校验**：在已有物化校验、评分和原稿比较中阻止内容或结构退化结果成为默认推荐；安全但无改善时保留原稿。

每一完整修复批次单独提交。使用已有测试框架，不恢复逐任务回执/强制子代理流程。
