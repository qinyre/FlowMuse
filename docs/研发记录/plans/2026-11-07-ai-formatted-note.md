# AI 整理为笔记

沿用白板选区菜单和现有 AI 面板，生成带标题、分节、段落和列表的可编辑成稿。预览后再确认，手写辨认不清的内容由模型标记待确认。

- 整理动作使用受限的标题与列表格式。客户端校验内容，再用现有编辑器元素排版。
- 分页和 PDF 笔记追加独立的空白整理页，内容超出时自动续页。无限画布在现有内容旁放置带纸张底色的整理稿。
- 成稿采用大标题、低饱和色分隔线、分节标题和统一正文节奏。用原生文本元素保持可编辑、导出与协作兼容。
- 一次确认写入页标记与全部内容，走现有场景提交和撤销链路。原稿保留。

静态分析通过，全量回归通过 2140 项，跳过 5 项。测试覆盖格式校验、预览确认、长文续页、PDF 页标记和一次撤销。用本地 Web 样稿核对中文字体和页面层级，真实模型和双端协作待实测。
