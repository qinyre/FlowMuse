# AI 回复来源定位

P0 第一项已提供选区、当前页和整篇文字来源。本轮实现 P0 第二项，让回复中的引用可以返回发送给模型的笔记内容。

- 在现有文本和图片请求顺序上约定引用编号。只有本次请求中的编号可用于定位，回复里的其他链接不触发导航。
- 文本以原元素 ID 定位，长段切分后仍指向同一元素。页面以页面 ID 定位，单页框选使用页内坐标。跨页截图定位到覆盖面积最大的页面。失效时提示用户。
- 回复保留本次发送的来源入口。查看原文时暂收起助手，在画布上高亮对应区域，通过返回按钮恢复同一回复。
- 定位只移动本地视口。新增的定位锚点不随网络请求发送，也不写入场景或本地存储。引用只说明模型指向的来源，不能验证模型结论。

静态分析通过。实现期间全量回归通过 2136 项，跳过 5 项。定向复测覆盖请求编号、切分映射、失效引用、页面重排，以及在白板实际点击引用并返回同一回复。真实模型与线上 Web 待验证。
