# R1–R7 复审修复记录

基于 `672b3b4`，2026-09-16。修复限定 V3 识别与候选链，不修改 V1 编辑器/识别引擎及服务端旧协议。原有 R9 离线报告和评测工具保持不动。

## 修复内容

1. **结构冲突准入**：`StructureResult.conflictedUnitIds` 显式记录未解冲突；语义账本、障碍块投影与替换后置守卫读取同一事实。不再只记 warning。
2. **真实局部重分组**：疑难同一行邻区合并成员、重算可视外框、重新渲染；旧资产与旧区域结果失效。新成员集合不能继承旧 `recognized` 状态。不同区域可共享请求批次，但不因此合并分区。复核失败/预算截断的疑难区域保留原件。
3. **原生组合**：V3 文档入口在放置前将完整原生文本/图片闭包合成一个放置块，物化整体等比变换一次，保留元素身份、正文和分组；重映射块间关系与原子组。含锁定、非准入成员或跨页成员的组合不进入该正向路径；保留源不得被顺带修改。不是任意图形组合的通用重排器。
4. **操作总预算**：pipeline 全生命周期计时器同时取消网络与本地资产构建；各区域渲染前后检查预算，停止后续区域并保留源。底层正在执行的单次原生光栅化不能强行抢占，但迟到产物不会被接纳，资源按既有 finally 路径释放。
5. **分区纠错**：真实 wiring 使用 `CorrectionPatchApplier` 做 merge/split 校验与逆 patch；拒绝重复区域和过期代次。`undo-region` 意图应用最近一次分区逆 patch，同样进入新代次、受影响区域重识别和候选链。它是纠错处理器入口，不新增独立 UI 按钮。
6. **旋转裁剪**：初始分区和超限二分子区域采用 `conservativeVisualBounds`，与现有纠错边界口径一致。
