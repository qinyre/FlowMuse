# 协作创建者信息挤压属性面板

## 原因与修复

200px 桌面属性面板在同一 Row 中放置创建者说明和带完整用户名的按钮。按钮优先占宽后，说明被压成逐字竖排；长用户名及历史会话后缀还会导致横向溢出。

共享 `_AttributionSection` 改为上下排列：说明最多两行、按钮单行省略，悬停或长按可查看完整信息。保留原有聚焦回调，同时覆盖桌面面板和紧凑底部面板。未改 Scene、History、归属数据、协作协议或后端。
