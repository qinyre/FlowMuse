# 笔型名称显示方框

笔盒中的铅笔、圆珠笔、钢笔、毛笔、荧光笔名称出现缺字方框。名称源码正常，共享 `StudioRailIconButton` 使用新的 `DefaultTextStyle` 只设置颜色，导致主题的中文字体和回退字体被覆盖。已补回归，修复前实际继承字体为 null，无法满足 `FlowMuseSans` 的断言。

改为合并继承样式，仅覆盖按钮前景色；笔型标签的缩放区域使用剩余纵向空间，避免恢复主题行高后双倍字号溢出。未更改文字内容、字体资产或 Web 启动优化策略。

编辑器 UI 回归 209 项通过，包含笔型选择、压感及触控笔交互。静态检查和 Web 发布结果见后续记录。未进行平板实机复测。
