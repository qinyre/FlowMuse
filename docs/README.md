## 文档生命周期

- **现行说明**描述可用行为和约束，与源码、配置一同维护。决赛计划区分已实现、已发布、待实测和未开发；计划不自动授权执行或上线功能。
- **历史研发记录**（plans/specs/research/troubleshooting/evidence/archive）记录当时条件。旧分支、包、临时 build 路径和“待合并”不代表今天的状态；临时产物未入库时不保证仍存在，不伪造新的实测结论。
- **有效契约与证据**继续保留：机读协议、fixture、门禁材料、采纳的设计、事故说明、授权及可复现验收入口。机器使用的 docs 文件不能仅因日期早删除。
- **被取代的建议与重复草稿**在确认引用和工具依赖后清理；历史原稿可由 Git 查阅，不在当前树复制一份备份。清理依据见[本轮记录](研发记录/plans/2026-10-27-documentation-refresh.md)。
