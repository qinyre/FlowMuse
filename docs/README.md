## 目录用途

| 目录 | 存放内容 | Git 管理 |
| --- | --- | --- |
| [项目说明](项目说明/) | 产品需求、架构约束、市场与发展方向 | 是 |
| [技术设计](技术设计/) | 架构、接口、数据模型和专题设计 | 是 |
| [研发记录](研发记录/) | 实现计划、规格、调研、排障和证据 | 是，运行时状态除外 |
| [复赛演示视频](参赛文档/复赛演示视频/) | 视频工程、脚本、选定成片 | 是，原片、配音及缓存除外 |
| 验收材料 | 实测附件、验收报告、本地历史产物 | 仅本地 |
| 周报与总结报告 | 成员周报和课程过程材料 | 仅本地 |
| 其他参赛文档 | 报名与竞赛过程资料 | 仅本地 |

研发记录沿用现有分类：`plans/` 放实现计划，`specs/` 放设计规格，`research/` 放调研，`troubleshooting/` 放排障，`evidence/` 放验收证据，`archive/` 放历史文档，`third_party/` 放第三方材料。

## 本地历史产物

`验收材料/本地归档/2026-09-28-仓库整理/` 收纳了原先散落在仓库及 App build 目录里的历史安装包、日志、截图、部署备份和一次性脚本。打开其中的 `README.md` 可查看用途，`迁移清单.json` 可查原位置和新位置。

归档按原目录层级保存。旧文档中的历史 build 路径，可在该归档下按同样路径查找。一次性脚本保留原内容，重新运行前按清单恢复到原位置，以保留原有相对导入关系。

视频输出目录保留当前成片、旁白版和制作底片；旧成片集中在 `参赛文档/复赛演示视频/output/history/`，旧审片日志与截图在其 `review-files/` 下。
