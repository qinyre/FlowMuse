核对日期：2026-09-25。依据本地 `2024-se-17` 主分支 `71fe6c4`、当前功能入口及其调用链、需求／架构文档、近期提交。这里的“已核对”指源码和入口存在；本轮没有在各平台执行真机功能验收。最终旁白须以录到的实际行为为准。

## 产品定位

FlowMuse 是跨平台协同白板，面向学习笔记、会议讨论、设计草稿与灵感记录。完整特色包括自研 Markdraw 内核、自然介质书写、手写转字、V3 图文排版、AI 视觉上下文、可编辑思维导图、带创建者聚焦的加密协作、好友邀请、双向文本表达以及鸿蒙原生入口。视频用学习资料作统一演示素材，但产品表达覆盖这些能力。

## 需要纠正的旧资料与边界

1. **智能排版只按当前 V3 展示。** `2026-09-21-remove-legacy-smart-layout-switch-to-v3.md` 记录旧模板卡片与旧草稿编辑流程已删除；需求文档“演进”章节仍混有旧历史描述。当前 V3 支持角色纠正／保留原件，不承诺旧版逐字校对、拖拽任意重排或固定三张模板。
2. **手写数学识别不等于 AI 检查公式。** 两个当前手写 UI 调用 `_buildInkRecognitionRequest` 时均走默认 `hint='text'`；服务端只有显式 `hint='math'` 才走 Math。结果解析虽支持数学元素，本轮未找到 UI 的数学模式切换链。视频使用已存在的 AI 视觉“检查公式”入口，暂不写“专用手写公式一键转换”旁白。
3. **网盘备份是预留入口。** 当前可拍的是本地备份；登录同一账号也不能宣称所有本地笔记已自动云同步。
4. **私聊与白板加密边界不同。** 白板协作消息／快照端到端加密，普通私聊正文保存在服务端；不要写“全应用所有消息均端到端加密”。
5. **多端协作不等于鸿蒙自由流转。** 旧发展计划中的端侧 OCR、端侧大模型、自由流转、报点预测、智能体入口不能作为本次已实现能力直接入片。
6. **鸿蒙特性看真机。** 服务卡片、华为授权、手写笔压感、Pen Kit 均有代码入口；可拍结果需设备及能力支持。构建成功、软件测试或 Web 演示不能替代该端真机体验。
7. **不写未测性能数字。** 连续书写／双端同步以实际镜头说话，不把调度窗口称为实际端到端延迟，也不直接宣称固定帧率或识别准确率。
