# FlowMuse 复赛演示视频

当前交付是**功能盘点、可拍摄脚本、可编辑分镜预演**。正式队名已填写为**青天小老爷**；还没有实机录像与真人旁白，所以预演中明确显示待录制位置，不能直接提交比赛。

先看 [功能盘点与镜头取舍](功能盘点与镜头取舍.md)，再看 [逐镜录制脚本](录制脚本.md)。初始剪辑计划 **4 分 48 秒**，八组实机镜头，V3 智能排版暂分配 60 秒；各段可按实际素材调整，总长自动计算。正式母版设置为 1920×1080、30 fps、H.264 MP4。

本轮叙事改为同一份“二叉树小组复习笔记”：课程 PDF → 书写批注 → 手写／语音转字 → V3 排版 → 同内容思维导图 → 同伴补充 → 导出复用 → 桌面继续。八组功能与原分配时长全部保留；开场前 6 秒先预告排版和协作结果，后 4 秒进入品牌；片尾前 4 秒依次回顾笔迹、排版、共创三项成果，后 4 秒显示品牌与队名。PDF 和语音段同时说明实际对应的鸿蒙原生能力，不等到片尾才介绍平台价值。

v4 使用新的“正在创作的纸面”主题：纸白、石墨黑与鲜绿，笔迹收成纸页，真实应用截图占据主要画面。先看 [32秒纸面主题样片](output/FlowMuse-纸面样片-v4.mp4)（1920×1080、30 fps），再看 [完整纸面预演](output/FlowMuse-纸面预演-v4.mp4)（288秒、1280×720、15 fps）。使用 frontend-design 与 HyperFrames creative 设计规范，经独立审美评审修整了视觉母题和截图裁切。两者有原创合成 BGM 与少量提示音，尚无正式配音；完整预演保留脚本字幕。音源见 [SOURCES-LICENSE.md](edit/public/audio/SOURCES-LICENSE.md)。

此前的 [v3叙事样片](output/FlowMuse-叙事样片-v3.mp4) 与 [v3完整预演](output/FlowMuse-叙事预演-v3.mp4) 保留用于比较。

历史静音版保留供比较：[v2 电影感样片](output/FlowMuse-电影感样片-v2.mp4)、[v2 完整预演](output/FlowMuse-电影感预演-v2.mp4)、[旧版分镜预演](output/FlowMuse-分镜预演.mp4)。素材来源与性质见 [视觉规范](DESIGN.md)，图像生成记录见 [image-prompts.md](image-prompts.md)。

## 本地预览

当前制作脚本面向 Windows x64，需要 Node.js 和 Chrome。下面的目录切换命令均从仓库根目录执行；首次使用先安装锁定的依赖。

```powershell
Set-Location 'docs/参赛文档/复赛演示视频/edit'
npm ci
npm start
```

打开终端输出的地址，选择 `FlowMuseStyleSample` 查看 32 秒纸面样片，或选择 `FlowMusePreview` 查看完整预演。v4 有背景音乐和少量提示音，但不带配音；底部字幕是按脚本分配的旁白文字，并非语音识别结果。片头、转场和录制步骤已排好。样片中的三组画面分别是历史 Android QA 截图、历史 V3 界面截图、协作组件测试截图；已在画面标注性质。功能示意与这些历史截图均不代表本轮真机实录或双端同步实测。

## 素材录制

按功能分八段录制，不必一口气拍完，也不用盯秒表。拍清楚操作和结果，允许停顿、重试；每段前后留约 3–5 秒，原始素材可以长于或短于初始分配，后期再定各段净时长。统一横屏；平板可以保留原始比例，后期完整缩放。所有实际同步镜头保持正常速度，AI 等待如剪短须标明。用演示账号和样例内容。

| 原始素材名称 | 初始剪辑计划（可调） | 核心画面 |
|---|---:|---|
| `01-library-pdf.mp4` | 22 秒 | 分类搜索、分页／无界、PDF、多页导航 |
| `02-natural-ink.mp4` | 34 秒 | 五种笔刷、铅笔／毛笔、压感、叠涂、切笔恢复、手指操作 |
| `03-recognition-voice.mp4` | 24 秒 | 手写转字、边写边排、语音转字 |
| `04-smart-layout.mp4` | 60 秒 | 原稿、V3 真实预览、图文关系、结构纠错、应用与撤销 |
| `05-ai-mindmap.mp4` | 35 秒 | 视觉问答、追问、确认生成、导图继续编辑 |
| `06-social-collaboration.mp4` | 45 秒 | 好友私聊、直接邀请、双端同步、创建者聚焦 |
| `07-markdraw-export.mp4` | 30 秒 | 双向文本、图元素材库、激光笔、导出／本地备份 |
| `08-harmony.mp4` | 20 秒 | 桌面卡片、账号入口、真机 Pen Kit 取色 |

建议原始录像放在本目录 `raw/`（按需建立）。先从原片挑选有效内容，再将剪好的片段放进 `edit/public/footage/`。后期给每段预留 **0.4 秒**转场尾帧；这由剪辑处理，不要求录制时精确计时。片段比当前计划短时，调整计划，检查脚本会提示对应场景。

`timeline.json` 中每个场景的 `duration` 是可修改的剪辑净秒数（正整数）；总长、后续章节起点和字幕自动更新。例如资料库从 22 秒改为 29 秒，后面的章节和字幕都会顺延 7 秒。每段的 `steps.at` 和 `cues` 都从本段 0 秒起算；缩短某段时，只需校准该段步骤和旁白，不必改后面所有时码。字幕草案不会自动变速匹配实录，正式旁白在画面剪好后录制并校准。运行 `npm start` 或 `npm run check` 更新脚本与字幕；预演可以暂时超过 5 分钟，正式导出会检查比赛时长限制。

时长回归已加入 `npm run check`：覆盖场景增减、后续字幕顺延、字幕越界、超时预演、提交时限及短素材提示。本轮叙事调整为 33 条旁白草案，各段结尾至少留 2 秒观察结果。步骤的 `screenLabel` 是上屏短句，`detail` 保留给拍摄与验收；`badge` 只标注实际使用的鸿蒙能力，换平台或不支持的硬件必须同步移除对应标识和旁白。脚本与字幕由 `prepare.mjs` 随时间轴生成，v4 沿用这套叙事与时间轴，v2/v3 视频保留供比较。

`timeline.json` 的 `team` 已填写“青天小老爷”。先剪画面，再按当前总时长对齐配音（含静音段，不再要求固定 288 秒），保存为 `edit/public/narration.wav` 或 `narration.mp3`。现场语音输入操作声若需要保留，后期合并进这条母音轨；素材原声默认静音，避免双声。

## 三个插件在工程中的作用

- **HyperFrames**：`intro/` 中的品牌片头，使用实际应用图标、笔迹成页图形及 GSAP 动画，输出 `intro-v4.mp4`。CLI 从 0.8.75 升级至 0.8.78；升级后原片头完整 `check` 已通过。
- **Remotion**：`edit/` 中的完整时间轴、八段素材替换、转场、预演字幕和母版输出。模板下载失败后按官方标准入口创建最小工程，依赖锁定在 `package-lock.json`。
- **Yaps**：针对最终有旁白的母版自动转写、校对及烧录字幕。本轮插件 runner 返回本地 CLI 不可达，**尚未转写，也尚未生成 Yaps 字幕成片**。根据 Yaps 插件的 “Stop until local reachability is restored” 要求，自动字幕阶段暂缓。可[下载或更新 Yaps](https://yaps.ai/download)，在本机打开一次，再从本地 Codex 任务继续。无需另装 CLI 或手工配 PATH。

## 校验与导出

```powershell
Set-Location 'docs/参赛文档/复赛演示视频/edit'
npm run check
npm run render:sample
npm run render:preview
# 补齐八段录屏与旁白后（队名已填写）：
npm run check:final
npm run render:clean
```

`render:clean` 生成 `output/02-演示视频青天小老爷-无字幕审片.mp4`，不会带入预演水印和草案字幕。素材不全会明确失败。之后交给 Yaps，使用清爽的 minimal／cinema 样式，逐条校对 FlowMuse、鸿蒙、Markdraw 等术语，验证输出，再保存为正式文件 `02-演示视频青天小老爷.mp4`。这一步完成前不把预演命名为提交版。

重新渲染片头时，使用工程内随 npm 安装的 FFmpeg/FFprobe（未安装系统软件）：

```powershell
Set-Location 'docs/参赛文档/复赛演示视频/intro'
$env:PATH = (Resolve-Path '..\edit\node_modules\@ffmpeg-installer\win32-x64').Path + ';' + (Resolve-Path '..\edit\node_modules\@ffprobe-installer\win32-x64').Path + ';' + $env:PATH
npm run check
npx --yes hyperframes@0.8.78 render --output ../edit/public/intro-v4.mp4 --fps 30 --quality high --workers 2
```

DM Sans 字体已随项目依赖保存，授权见 [DM-Sans-LICENSE.txt](DM-Sans-LICENSE.txt)；中文优先使用本机 MiSans Regular，回退 Microsoft YaHei。系统字体不随工程分发；换机器渲染须核对字体与换行，或替换为有授权的中文字体并重新检查排版。
