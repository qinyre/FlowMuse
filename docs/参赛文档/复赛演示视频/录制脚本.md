## 01:30–02:30｜04 / V3 智能排版

**目标镜头：04-smart-layout.mp4；正文 60 秒，另留转场余量。**

| 成片时码 | 操作 | 画面验收 |
|---|---|---|
| 01:30 | 完整拍原稿 | 准备同页的手写／打字标题、正文、图片与说明；先展示真实凌乱页，保留对比依据。 |
| 01:39 | 进入当前页智能排版 | 点击工具栏最右侧“全局识别排版”→“开始智能排版”。保留阶段提示，压缩等待时必须加标注。 |
| 01:50 | 切换候选、对照原稿 | 在真实候选间切换，切到原稿／并排对照；重点看标题层级、图与说明的关系。不要画固定三模板卡。 |
| 02:00 | 调整内容结构 | 选择真实内容块，演示“作为标题／正文”或“保留原件”之一，等待新预览。当前不宣称逐字校对或任意拖拽排版。 |
| 02:10 | 应用与单次撤销 | 点击“应用所选排版”；展示整页，再单次撤销回原稿。保留清晰前后对照结尾。 |

- **01:31–01:39** 面对整页凌乱图文，使用 V3 智能排版。
- **01:40–01:49** 从当前页识别内容，理解标题、正文，以及图片和说明的关系。
- **01:50–01:59** 先看真实排版预览，再与原稿对照，选择合适的方案。
- **02:00–02:09** 我们还可以调整内容块的角色，或选择保留原件。
- **02:10–02:19** 确认应用之后，排版才真正改变白板。
- **02:20–02:29** 一次撤销就能回到原稿，把最终决定留给使用者。
