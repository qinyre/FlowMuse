# FlowMuse 复赛视频视觉规范

## 当前主题：正在创作的纸面
v4 按用户最新要求推翻翡翠墨色暖金主题。使用 frontend-design、HyperFrames creative 规范，并由独立审美智能体检查产品契合度、主体比例、连续镜头变化及截图裁切。保留 FlowMuse 应用图标，以笔迹、内容对齐、页面与共同编辑为视觉语言。

## 色彩与字体
纸白 #F6F5F0、石墨黑 #171A18、鲜绿 #42DD91；说明文字用 #087D5D / #536259，边界 #D9DFD6。鲜绿用于笔迹、高亮与选中重点，不以渐变或发光制造层次。实际截图保留原色。

英文品牌使用工程已有 DM Sans；中文优先使用本机已安装的 MiSans Regular，回退到 Microsoft YaHei。不复制或分发这两种系统字体文件，换机器须核对字体和换行。主标题约 100–140 px，品牌字可达 262 px；正文 30–36 px、来源标记 22–25 px。主画面左右约 96 px 安全边距，底部约 165 px 留给字幕。

## 构图和动效
品牌：大字与一笔展开的墨迹，笔迹末端成为纸页；移除玉石玻璃主视觉与金色边线。参考 HyperFrames registry 的 marker-highlight 描线原则，以本地 GSAP 和 SVG 定时实现，不引入新依赖。

正文：书写采用大幅笔刷画面；排版用横向预览对照；协作用邀请界面局部与明确标注的共创关系图。完整概念分镜改用粗细有层次的黑绿笔迹、真实课程主题与更大的图形主体。真实录像仍完整缩放，短操作提示不替代实际操作。

动效由写出笔迹、内容进入、对齐、引导标记退出构成；不持续漂浮或扭转截图。每段末尾至少留2秒观察结果；原有八组功能、33条旁白草案及可调时长保留。片尾署名“青天小老爷”。

- 协作邀请：组件测试截图，保留性质标记，不作为双端同步实测证据。

v4：32秒1080p30样片、288秒720p15完整预演，H.264 MP4。工程可调每段时长，后续字幕与章节自动顺延；实际录屏不要求卡秒。缺八段实录和正式旁白时仍保留预演标识，正式导出检查继续拦截。Yaps最终配音字幕尚未制作。
