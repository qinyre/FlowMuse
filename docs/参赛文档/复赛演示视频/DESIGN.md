# FlowMuse 复赛视频视觉规范

## Style Prompt
沿用 FlowMuse 官网的浅色纸面与绿色强调色，以及应用现有图标。像一张正在被整理的白板：大字、留白、细线、少量手绘路径。真实操作画面始终是主体。该选择已由用户确认。

## Colors
- 画布：`#FAFAF9`，来自 `flowmuse-website/styles.css`。
- 正文：`#1C1917`，来自官网 primary。
- 强调：`#059669`，来自官网 accent。
- 次要文字：`#57534E`，官网 muted 的加深版本，用于视频可读性。
- 分隔线：`#E7E5E4`，来自官网 border。

## Typography
英文品牌沿用 DM Sans；中文使用本机 Microsoft YaHei。无衬线字体作为画外说明，保留录屏中应用自身字体。1080p 标题 76–132 px，字幕 38 px。左右安全边距 100 px。

## Motion
片头由 HyperFrames / GSAP 制作。正文用 Remotion 编排，章节交接溶解 0.4 秒；操作片段保持正常速度，等待如压缩必须标明。出现动画 0.35–0.7 秒，观看操作时不加持续位移。

## What NOT to Do
- 不重画假界面冒充运行录像。
- 不用霓虹渐变、粒子和连续推拉抢走操作焦点。
- 不把规划书中的待实现能力写成已验证成果。
- 不编造延迟、准确率、用户规模或上架状态。
- 缺录屏时始终显示“分镜预演”，不能导出为可提交成片。
