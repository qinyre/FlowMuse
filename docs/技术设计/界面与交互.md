# 界面与交互约定

> 2026-10-27 按 main `97c2a6c4` 核对。本文描述实际 Flutter 界面，替代未采用的 ArkUI/HDS 外壳改造提案。原生能力通过适配层接入，不要求重做一套鸿蒙专属主界面。

## 视觉与复用

- 纸面与低饱和主题服务于阅读、书写和共同编辑，正文保持清晰，不在画布热路径增加模糊、循环光效或逐元素动画。
- `AppTheme` 统一六种预设、FlowMuse Sans、输入及按钮语义色。界面字体与白板内容字体分开维护。
- `AppSpacing` 管理尺寸与间距；页面复用 `AppShell`、`SharedSidebar`、`RightPageScaffold` 和 `RightPageHeader`，不另建导航体系。
- 卡片使用 surface，设置输入框与选择器使用 surfaceContainer，保留聚焦边框、悬停和禁用反馈；不靠颜色单独表达状态。

## 页面与导航

资料库侧栏支持 docked / drawer / 收起状态，宽度变化与笔记布局过渡保持内容和选中项。单笔记下拉菜单位于笔记名旁。搜索当前检索本地标题和副标题，范围可按笔记本、标签筛选；正文全文索引仍在决赛计划中。

设置页标题居中，导航按账户与数据、外观与书写、应用与隐私分组。正文最大宽度 960px，主题使用六张预览卡，窄屏和大字号自动减列。分类切换保留主体状态，回到新分类顶部；快速切换只保留一个当前标题。

搜索框、筛选菜单和多选操作栏采用现有焦点及操作模型，不由页面尺寸变化清空查询或选择。工具和账号操作保持既有回调，不为视觉调整重置用户设置。

## 动效与输入

动效使用 [AppMotion](../../FlowMuse-App/lib/shared/widgets/app_motion.dart) 的统一时长和曲线，遵循系统减少动画偏好。进入、退出和重定向应可中断，离页清理 ticker；书写和远端实时墨迹直接响应，不套页面过渡。

页头在窄屏或大字号下分行，操作保留可点击区域。输入焦点、软键盘、鼠标、触控、手写笔与浏览器默认行为分别处理；Web 笔记画布支持 Ctrl+滚轮缩放，普通滚轮仍用于原有浏览。

白板工具栏使用现有 `HoverTooltip`，气泡不吞掉笔尖点击；设置等普通页面沿用框架组件。笔身双击和重压临时橡皮只改变本机工具状态，不能给远端强制换工具。

## 协作反馈

聚焦、查看位置和跟随是本机视图操作；位置提示须由接收者确认后才移动视角。聚焦/跟随状态集中于协作顶栏及菜单，不挤压头像、不在画布中央长期遮挡内容。

本地保存、网络传输和协作成员状态分别表达，提示须对应实际事件；光标可用不能作为正文已同步的证明。只读角色、内容锚点评论和完整同步状态体系的新增范围见决赛计划。
