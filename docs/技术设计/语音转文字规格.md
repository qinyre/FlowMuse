# 语音转文字：当前实现与验收边界

> 2026-10-27 按 main `97c2a6c4` 核对。早期后端 ASR 提案已被本页替代，当前服务端没有 `/api/speech/transcribe` 接口。

## 用户流程

白板麦克风入口启动识别，临时结果在本地界面预览；最终结果通过现有文本插入流程成为普通文本元素，支持撤销、保存、导出和协作。取消、离页、退后台及旧会话回调不得提交临时文字。语音输入服务于笔记记录，不提供语音会议。

## 平台实现

| 平台 | 当前路径 | 边界 |
| --- | --- | --- |
| HarmonyOS | `SpeechRecognitionChannel.ets` 调用 Core Speech Kit | 需麦克风权限；当前引擎配置 `online: 1`，不宣称断网可用 |
| Android | 原生 `SpeechRecognizer`；不可用时尝试 Sherpa 离线服务 | 依赖系统服务、权限及随包模型可用性，不将一种机型的结果推广到所有安卓设备 |
| Web | `SpeechRecognition` / `webkitSpeechRecognition` | 由浏览器提供能力，通常需要 HTTPS/localhost 与麦克风授权，识别服务可能联网 |
| 其他原生端 | 同一 MethodChannel 门面和各平台注册实现 | 未注册或能力不可用时返回 unavailable，不以接口存在证明实机通过 |

应用没有经 FlowMuse Go 服务上传录音的识别通路。音频是否由系统或浏览器识别服务处理，取决于平台实现；不能笼统宣称所有端离线、录音绝不出端。应用侧不将原始录音保存为笔记附件或广播到协作房间；确认的文本仍按普通笔记数据处理。

## Dart 契约

`SpeechRecognitionService` 提供 `isAvailable()`、`events`、`start(locale)`、`stop()`、`cancel()`、`dispose()`。

- `SpeechRecognitionResult(text, isFinal)` 区分临时结果和最终结果。
- `SpeechRecognitionStateChanged` 表达 idle / starting / listening / stopping。
- `SpeechRecognitionFailed` 表达 permissionDenied、unavailable、busy、noSpeech、network、cancelled、unknown。
- 工厂用条件导入选择 Web 或原生实现；原生通道为 `flow_muse/speech_recognition`。
- 原生启动携带 generation；新会话、取消和销毁隔离旧回调，最终结果去重。缺插件或能力不足保持编辑器可用。
